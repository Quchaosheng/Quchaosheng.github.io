实验记录模板

REPRODUCIBLE RECORD

每一次测量、仿真或台架验证都从同一份记录结构开始。模板不会把一次成功写成普遍结论，它要求把可复查工件和不能外推的部分一起留下。

定义问题与阈值→冻结环境与输入→运行并保存工件→解释结果与边界→决定补测 / 回归 / 回滚

使用规则

  1. 先写通过阈值和失败动作，再运行命令。
  2. 不覆盖失败工件；新尝试用新的运行 ID 和目录。
  3. 记录原始输出的位置与哈希，而不是只贴一张成功截图。
  4. 结论要写明“本次能证明什么”和“不能证明什么”。

记录骨架

项目页和证据日志应只引用已经有对应记录和工件的结论。真正的实验结果出现后，再把这份骨架替换为该次运行的事实。
