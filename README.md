# quchaosheng.github.io

技术笔记与项目记录站点，发布于 <https://quchaosheng.github.io/>。

内容围绕 Linux 内核、ROS 2、嵌入式与机器人系统；其中项目页对应各公开仓库的
主线、证据环境和未验证边界，笔记按命令、函数名和问题关键词可检索。

## 这个仓库是什么

本仓库是 **Hexo 构建产物**，由发布流程生成后推送，`master` 分支内容即线上站点。
它不是手写源码：直接修改这里的 HTML 会在下一次发布时被覆盖。

- 站点生成器：Hexo 7.3.0（主题：Chic）
- 文章与项目页源文件位于本地 Hexo 工程，不在本仓库
- 提交信息形如 `site: publish <commit>`，`<commit>` 指向生成该次输出的源提交

因此本仓库只接受生成产物；内容修订请在 Hexo 源工程中完成并重新发布。

## 结构

| 路径 | 内容 |
| --- | --- |
| `2026/<月>/<日>/<slug>/` | 按日期归档的笔记 |
| `projects/` | 各公开项目的说明页 |
| `category/`、`archives/` | 按主题与时间浏览的入口 |
| `paths/`、`modules/`、`guides/` | 学习路线与主题索引 |
| `search/`、`search.json` | 站内搜索索引 |
| `atom.xml`、`sitemap.xml`、`robots.txt` | 订阅、站点地图与爬虫配置 |

## 内容约定

- 笔记日期是整理日期，不是首次出现时间。
- 引用外部资料时保留来源，并尽量用官方文档、上游代码或可运行命令交叉验证。
- 仿真、虚拟总线和生成图像只能说明软件路径，不能替代真机结论；每条结论都会标注
  已证明与未验证的边界。
- 已有页面的永久链接保持稳定。
